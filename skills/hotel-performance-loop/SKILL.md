# 酒店数据复盘

## 分析流程

1. 只统计当前账号和指定时间窗口的数据，区分草稿、待发布、失败和已发布。
2. 计算曝光、互动率、完播率、收藏、分享、主页访问、咨询和转化；缺失指标明确标记，不补零冒充真实数据。
3. 与近 7 条、近 7 天和同类型内容基线比较，识别峰值与下降。
4. 提取钩子、主题、素材分类、发布时间和 CTA 的共性，不把相关性写成因果。
5. 输出保留、放大、停止和实验四类动作，并形成下一轮选题权重。
6. 检查素材消耗：高频首图、低库存分类和长期未使用素材。

## 实验规则

- 每轮只改变一个主要变量：钩子、封面、主题、发布时间或 CTA。
- 指定假设、基线、目标指标、观察窗口和停止条件。
- 数据量不足时标记低置信度，不直接形成长期规则。
- 营销内容同时看转化，不能只看播放量。
- 发布失败和审核阻断属于流程指标，不计入内容效果。

## 输出

返回 `performanceSummary`、`wins`、`losses`、`anomalies`、`contentPatternWeights`、`materialActions`、`nextExperiments` 和 `confidence`。

指标定义与迭代模板见 [references/metrics-loop.md](references/metrics-loop.md)。
